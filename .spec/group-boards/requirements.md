# 需求结论：分组桌板（Group Boards）（2026-09-05，用户第 65 轮提出）

## 1. 目标
让侧栏每个分组标题（model / config / runtime / resource / session）都成为
**一等桌板**：点标题 = 切到该组专属桌布（独立布局区、独立卡片状态），
「全部」保留为总览板。现状只有「过滤」，本需求把它升级为「每标题一张桌布」。

## 2. 用户已拍板四题（第 65 轮问答）
| 题 | 决定 |
|---|---|
| 形态 | **分组桌板**（非单页分区，非两者都要） |
| 关闭状态范围 | **每板独立**（config 板关卡不牵连 model 板/全部板） |
| 布局深度 | **自动排布先做**（拖拽+摆位记忆=后续可选项，非本期） |
| 深链 | **要**：`#board=<组名>` / `#board=all`，刷新/收藏直达 |

## 3. 现状基线（自下而上实核，canvas-shell/src/app.rs）
- `visible_cards(model, selected, closed)`：点侧栏已按组过滤（升级起点）。
- 关闭集**全局一份**（localStorage `dsh.canvas.closed`）——每板独立的反面，本期改造点。
- 布局=自动（声明格+实测装箱），按当前可见集重算——天然可按板独立，无需新算法。
- 无板级 URL。

## 4. 边界与非目标
- 单元层（13 张卡）、声明契约、RPC 面：**零改动**。
- 拖拽摆位与摆位持久化：非目标（用户明确先做自动排布）。
- 单页分区/混合形态：已否决，不做。

## 5. 验收标准
1. 板内容=按 type 严格归属分区：config 板只显示 config 组卡片；「全部」板=全部卡并集；
   自动排布只排当前板卡集。
2. **侧栏点击语义（第 65 轮用户细化「逻辑类似如此」）**：
   - 点组标题（model/config/…）→ 切到该组桌板（再点回「全部」）；
   - 点组下卡片标题（如 model 组下「DeepSeek Provider」）→ 切到其所属组桌板并滚动聚焦；
     该卡在目标板/当前板处于关闭态时顺带重开；
   - 点「全部」→ 总览板。
3. 关闭集按板独立：板 X 上 ✕ 一张卡，只影响板 X；「全部」板自身另有闭合集。
   localStorage 键结构升级为「板→列表」（v2 键）；**旧全局键一次性迁移为「全部」板
   的闭合集**（老用户状态不丢）。
4. URL hash：`#board=config` 等直达对应板；切板实时更新 hash；无 hash 时默认「全部」。
5. 侧栏高亮与当前板一致；点「全部」回总览。
6. 回归护栏：e2e-audit T0–T11 全绿（T2/T9 关闭语义在默认 all 板上不变，断言改 v2 键）；
   新增 T12 板级断言（组/卡点击切板、板间闭合集互不牵连、hash 直达）。
7. 热插拔/持久化/折叠等既有能力在任一板上行为不劣化。

## 6. 默认假设（如不同请指出）
- 板的集合 = manifest 实际出现的 type 分组（动态，非硬编码五个）。
- 「全部」板也拥有自己的闭合集（与其他板平权），迁移来的旧键归它。
- hash 只记板名，不记卡片聚焦/滚动位（聚焦深链留后续）。

## 7. 此类需求最常见的错误
把闭合/布局状态仍留全局——「在 A 板关的卡 B 板也没了」，正是现状缺陷，
本期以每板独立为硬性验收（5.2）堵死。
